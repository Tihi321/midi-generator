## MDI-09: end-of-run result check for the agent (2026-10-28, branch MDI-09_agent-result-check)

A run could end "completed" with nothing made (MDI-08: a codex run made 8 tool calls and wrote no notes). `runAgent` takes `resultCheck { mutates, snapshot }`: when the model ends its turn after a mutating tool call and the app state (`get_song` without cursor / undo lines) equals the state before that call, it is sent back with "Your actions ran but the song is unchanged..." at most `MAX_RESULT_NUDGES = 2` times (`resultNudges`, `resultRetry()`; same names as Pixel Studio PAR-16). JSON-action mode checks the error guard first; native mode shares the check at its end of turn. Q&A runs are never nudged. Limit: the snapshot is the `get_song` summary (note counts per channel, orders, timing, instruments), so a write that only changes pitches in place looks unchanged. Ticket: `.claude/tickets/MDI-09-agent-result-check/`.

## MDI-10: synthwave with two sample chips, PlayStation SPU and Dreamcast AICA (2026-10-28, branch MDI-10_synthwave-ps1-dreamcast)

Two new chips, `ps1` and `dreamcast`, on one sampler core shared with the SNES (`src/core/synth/sampler/`; SNES output is bit-identical to before, checked by 50 render hashes and the golden files). **PS1:** 16 or 24 PS-X ADPCM voices at 44.1 kHz with the hardware ADSR, pitch modulation, a global noise generator, 512 KB of SPU RAM and the SPU reverb with the classic presets (`off`, `room`, `studio-small/medium/large`, `hall`, `half-echo`, `space-echo`, `echo`, `delay`). **Dreamcast:** 16, 32 or 64 slots with PCM16, PCM8 or 4-bit ADPCM, an AEG, an LFO, a resonant filter with its own envelope, 2 MB of AICA RAM and a DSP with reverb, chorus and delay presets. Instrument kinds `psx-sample` and `aica-sample`; 19 new generated recipes (supersaw, detuned and sync leads, Juno pad, analog and FM bass, arp pluck, synth brass, DX e-piano and bell, LinnDrum/808 kit with a gated snare) and the synthwave presets `<chip>.<role>.<name>`; `compose_track` moods `synthwave`, `outrun`, `darkwave`, `dreamwave` (defaults: ps1, dreamcast, ps1, dreamcast); UI for the reverb / DSP, RAM meters, a Voices select and both instrument editors; `export_midi` shares MIDI channels by GM program when a song has more than 15 melodic channels. `voices` is fixed in `new_song` and defaults to 16 (role layout V1..V16, drums on V13..V16), so `get_song` and `read_pattern` stay short (more than 16 channels: only channels with notes). Ticket: `.claude/tickets/MDI-10-synthwave-ps1-dreamcast/`.

Approximations (named in the guide and the file headers): the PS1 reverb runs at 22.05 kHz with a [1 3 3 1]/8 decimator and linear up-sampling and the Gaussian table is the SNES one, not psx-spx's own; looped samples are resampled to whole 28-sample ADPCM blocks. The reverb register values were entered from memory of psx-spx and still have to be checked against it (`half-echo`, `echo` and `delay` first). The AICA DSP is a Freeverb-style reverb plus chorus and delay presets, not the 128-step microcode; some AICA table values are modelled rather than documented (LFO pitch depth PLFOS in cents, key rate scaling, FLV to Hz, Q) and flagged in `aicaTables.ts` / `aica.ts`. The default voice count is 16 (24 or 32 / 64 only when asked for in `new_song`), which keeps the tools and the tracker manageable; the extra voices have no role layout. Merged MIDI tracks keep notes but not pitch bends and volume changes.

Follow-ups: warm the sample cache on the main thread before posting a song to the audio worklet (supersaw and pad loops are 16k samples, so a first load can glitch; Risk 6); give `SamplerVoice` a per-instrument target hook (`AicaVoice.startNote` swaps the readonly `target` through a cast today); listen to the synthwave presets and moods on both chips (only peak and RMS were checked); an AICA microcode DSP is out of scope.
